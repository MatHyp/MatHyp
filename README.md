### 🔭 What I'm Working On

- 🚗 **ParkSight**: Developing an AI-powered smart-city parking detection system using YOLO. We started as an engineering team project and are now preparing for commercial deployment and pilot tests with ZUT.
- 🏎️ **Engineering Thesis**: Building a WiFi-controlled RC car based on an STM32 microcontroller with driver assistance features and lane detection. Deeply learning embedded electronics to build robust hardware-software integrations.

### 🛠️ Core Projects

- 🌈 **[Raytracer in C++](https://github.com/MatHyp/Raytracer)**: A fully functional, CPU-based ray tracer written from scratch. Features recursive reflections, dynamic soft shadows, custom Wavefront OBJ parser, and highly optimized Bounding Volume Hierarchies (BVH).
- ⚙️ **[Lisp Interpreter](https://github.com/MatHyp/lisp)**: A complete Lisp interpreter implemented purely in C++ to deepen my understanding of compilers, AST parsing, and memory management.
- 📈 **[InvestMe](https://github.com/grzjan5219/InvestMe)**: A comprehensive web application for tracking cryptocurrency investments and analyzing market trends in real-time (Python, Flask, React).
